Fetch models from 9Router and convert to chatLanguageModels.json

Accepts: localhost, 127.0.0.1, 0.0.0.0, custom domain, or Cloudflare tunnel URL
🔒 Mixed content blocked?
Browser from https:// page cannot fetch http://localhost.

Options:
• Open this page via file:// — double-click index.html
• Run a local server: python -m http.server 8080
• Use the Paste JSON tab instead
• Use the .bat / .sh / .py script
How to get JSON:
curl -s -H "Authorization: Bearer YOUR_TOKEN" http://localhost:20128/v1/models
Copy the output and paste above, or download the fetch script from the Scripts tab.
💡 Workflow when localhost is not accessible:
1. Download a Fetch script → run on machine with 9Router access → produces models_raw.json
2. Come back here → Paste JSON tab → upload models_raw.json
3. Convert to chatLanguageModels.json → download or copy
