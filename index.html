check_circle File generated! Now install it:
  1. Click Download in the Editor panel to save chatLanguageModels.json.
  2. Copy the file to your VS Code user directory:
    %APPDATA%\Code\User\
  3. Restart VS Code.
  4. Press Ctrl+Shift+P (or Cmd+Shift+P on Mac) and type Chat: Manage Language Models, hit Enter.
  5. Locate your custom provider in the list. Click the gear icon next to it.
  6. Paste your API key into the input field and save.

For macOS: ~/Library/Application Support/Code/User/  |  Linux: ~/.config/Code/User/
